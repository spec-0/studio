## Installing

### Windows says "Windows protected your PC"

The installer isn't code-signed yet. Click **More info**, then **Run anyway**. To check the file
first, compare its hash with `SHA256SUMS.txt` on the
[releases page](https://github.com/spec-0/studio/releases/latest):

```powershell
Get-FileHash .\spec0-studio-windows-x64-setup.exe
```

### macOS warns that the app can't be checked

The Mac app is notarized, so a warning means the download is bad. Don't open it. Download it
again, and check it against `SHA256SUMS.txt` as described in [Install](/install).

### Studio won't start on Linux

Studio needs WebKitGTK 4.1 (Ubuntu 22.04, Debian 12 or newer). Builds are x86_64 only. Make an
AppImage executable with `chmod +x`.

## Specs

### My Swagger 2.0 spec looks different

Studio converts it to OpenAPI 3.0. The **Raw** tab shows the original. Swagger 1.2 and older
don't open. See [Swagger 2.0 specs](/library#swagger-20-specs).

### A `$ref` to another file doesn't resolve

Studio doesn't follow references to other files or URLs. Bundle the spec into one file, for
example with `npx @redocly/cli bundle openapi.yaml -o bundled.yaml`.

### I edited the spec file, but Studio shows the old version

Studio works from its own copy. Choose **Re-read from source** in the **⋯** menu on the API's card.
See [What Studio keeps](/library#what-studio-keeps).

### The request goes to the wrong server, or to a path like `/api/v3`

Pick a server in the address bar, or type a base URL. A local spec whose server is a path needs the
full address typed. See [The address bar](/requests#the-address-bar).

### A request body has values like `"string"`

That's a placeholder, used when the spec gives nothing better. Replace it, or add an example to the
spec.

## Networks

Studio may send HTTP requests to any host, because an API client has to reach whatever address you
give it.

### Requests fail behind a corporate proxy

Studio reads `HTTPS_PROXY`, `HTTP_PROXY` and `NO_PROXY`. When it's started without them, such as
from the Dock, set the proxy in **Settings → Network**. See
[Proxy](/network#proxy).

### "Certificate" or "unknown issuer" errors

Your system doesn't trust the server's CA. In **Settings → Network**, trust the CA's PEM bundle
for that host. Skip verification only when you have no bundle. See
[Certificates](/network#certificates).

### Check for Updates fails at work

The update check uses Studio's proxy setting but not its certificate settings. A network with a
private CA, or one that inspects encrypted traffic, can block it. Download the new version from the
[releases page](https://github.com/spec-0/studio/releases/latest) instead.

## Secrets

### Secrets aren't in the keyring on Linux

With no keyring running, a locked one, or no desktop session, Studio keeps secrets in an
unencrypted local file, and the Environments dialog says so. Install or unlock a keyring such as
GNOME Keyring or KWallet, then restart Studio. The values move into it.

### A long token won't save on Windows

Windows limits stored credential length. A longer token stays in Studio's local file, and the
Environments dialog says how many values that affects.

## Ports

### The local mock didn't start on port 4010

Another program has it. Studio picks the next free port up to `4099` and keeps it for that API. If
none is free, stop another local mock or free a port.

### The MCP server started on a different port

Port `47321` was taken, so Studio used the next free one. Copy the setup text from the MCP tab
again, or choose a port there.

## Agents

### My agent's request wasn't asked about, or was refused

Studio asks once per host. After **Allow for this session**, that host goes through until you press
**Stop agents** or quit. A refusal tells the agent why: you chose **Don't allow**, nobody answered
in five minutes, the host is blocked, or agents went over **Requests a minute**. See
[Approving what agents do](/mcp#approving-what-agents-do).

### My agent can't change a collection

Agents can change only their own drafts. See [Collections agents build](/mcp#collections-agents-build).

### Agent chat doesn't find my agent, or it needs signing in

Agent chat is new and its ACP adapters are young. A past chat can be read but not continued. See
[Troubleshooting agent chat](/agent-chat/troubleshooting).

## Questions

### Do I need a Spec0 account?

No. Only hosted mocks, your organisation's catalog, and publishing need one.

### Does Studio send my data anywhere?

No. There's no telemetry, and your data stays on your computer. See [Privacy and security](/privacy).

### Can I run a collection from CI?

Not yet. Collections run in Studio only.

### Does Studio run Postman scripts?

No. A [Postman import](/collections/postman) converts status checks and saved response values.
Other scripts aren't run, and the import summary says what was skipped.

### Is there support for GraphQL, gRPC or WebSockets?

Not yet. Studio is built around OpenAPI specs and HTTP requests.
