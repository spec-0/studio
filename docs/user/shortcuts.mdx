On Windows and Linux, use `Ctrl` wherever this page says `⌘`.

## Everywhere

| Keys | Action |
|---|---|
| `⌘O` | Add an API |
| `⌘P` | Switch to another API |
| `⌘L` | Back to the library |
| `⌘E` | Environments |
| `⌘,` | Settings |
| `⌘D` | Switch between light and dark |
| `⇧⌘Y` | Open or close the [console](/console) |
| `⇧⌘J` | Open or close the [agent chat](/agent-chat) |
| `Esc` | Close a dialog |

## An open API

| Keys | Action |
|---|---|
| `⌘↵` | Send the request |
| `⌘1` `⌘2` `⌘3` `⌘4` | Operations, Schemas, Graph, Document |
| `⌘\` | Show or hide the response pane |
| `/` | Search the operations |

## Request tabs

| Keys | Action |
|---|---|
| `Ctrl+Tab` | Next tab (`Ctrl` on every system, macOS included) |
| `Ctrl+Shift+Tab` | Previous tab |
| `⇧⌘]` and `⇧⌘[` | Next and previous tab (macOS only) |
| `⌘W` | Close the tab on screen |
| `⇧⌘W` | Close the window (macOS only) |

## Collections

| Keys | Action |
|---|---|
| `Shift+F10` | Open the menu for the selected operation (to add it to a collection) or step |
| `Alt+↑` and `Alt+↓` | Move the selected step up or down |
| `Delete` | Remove the selected step, while the step list has focus |
| `F2` | Rename the selected collection, in the list of collections |
