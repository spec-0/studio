## Give your coding agent your APIs

Studio runs an [MCP](https://modelcontextprotocol.io) server on your computer. Once it's on, a
coding agent can read the specs in your library, send requests, start mocks and run collections.
Its requests go through Studio, so they use your environments and are checked against the spec,
and you approve which hosts it may call.

Turn it on in the **MCP** tab, copy the setup text, and add it to your agent:

<Tabs items={['Claude Code', 'Cursor']}>
  <Tab value="Claude Code">

```bash
claude mcp add --transport http spec0-studio http://127.0.0.1:47321/mcp --header "Authorization: Bearer <your token>"
```

  </Tab>
  <Tab value="Cursor">

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "spec0-studio": {
      "url": "http://127.0.0.1:47321/mcp",
      "headers": { "Authorization": "Bearer <your token>" }
    }
  }
}
```

  </Tab>
</Tabs>

The copied text has your real token in place of `<your token>`. [Local MCP server](/mcp) covers
other clients, the tools an agent gets, and approvals.
