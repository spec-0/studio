**Spec0 Studio** is a desktop app for calling and testing APIs, built around your OpenAPI spec. You
open a spec, Studio builds the requests from it, and every JSON response is checked against what the
spec says. It runs on macOS, Windows and Linux, it's free and open source (MIT), and it works with no
account and no telemetry. See [Privacy and security](/privacy).

## What you can do

| Task | How Studio helps |
|---|---|
| **Send requests** | Forms come from the spec, with real field names, allowed values and example bodies. See [Sending requests](/requests). |
| **Check responses** | Each JSON response is checked against its schema, including fields the spec never mentions. See [Checking responses](/checking-responses). |
| **Read the data model** | Browse [schemas](/schemas) and how they link in the [graph](/schema-graph). |
| **Run flows across APIs** | A [collection](/collections) runs steps in order and passes values between them. |
| **Mock an API** | A [local mock](/local-mocks) in one click, or a [hosted mock](/hosted-mocks) to share. |
| **Work with your coding agent** | Agents use your APIs through the [local MCP server](/mcp), or chat in the [agent panel](/agent-chat). |

New to Studio? The [quick start](/quick-start) takes about ten minutes, from download to a coding
agent using your APIs.

## Finding your way around

The top bar has five tabs: **APIs**, **Collections**, **History**, **Mocks** (with a green dot while
a local mock runs) and **MCP**. On its right are the environment picker, **Agent** (`⇧⌘J`),
**Sign in** or your organisation's badge, and **Settings** (`⌘,`).

With an API open, [request tabs](/requests#request-tabs) sit under the top bar, then the API's bar:
its name and version, four views (**Operations**, **Schemas**, **Graph**, **Document**, on `⌘1` to
`⌘4`), **Local mock**, the hosted mock and **Run**. `⌘O` adds an API and `⌘P` switches between them.

The status bar shows running local mocks and the active environment on the left, and on the right a
running [collection](/collections/running), the last request's status and check, and the
[Console](/console).

The code is at [github.com/spec-0/studio](https://github.com/spec-0/studio).
