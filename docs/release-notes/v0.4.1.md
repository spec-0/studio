Spec0 Studio 0.4.1 makes the agent chat work without setup. Pick an agent and ask it to test an API: it already has Studio's tools, knows what you have open, and follows a short set of instructions written for Studio.

## What's new

- **An Agent button in the top bar.** It sits next to Settings, shows a dot while a chat is running, and turns amber when the agent is waiting for your approval. ⇧⌘J (Ctrl+Shift+J) still opens it.
- **Setting up an agent inside the panel.** The first time you open the chat, it lists the agents it found on your computer and how each one signs in. For agents it didn't find, it shows the install command. Pick one, Studio tests the connection, and you can start.
- **Studio's tools connect by themselves.** Starting a chat starts Studio's MCP server if it's off and connects the agent to it. If the server stops during a chat, the chat says so and offers **Reconnect**.
- **The agent knows where it is.** Your first message carries a short note about what's open in Studio: the API, the operation and the collection. You can open the **Studio context** chip to see exactly what was sent.
- **Instructions written for Studio.** Studio gives the agent a short set of instructions and four task guides: testing an API, checking a server against its spec, building a collection and explaining a failed run. They're in the repository at `src/agent-profile/`, so you can read exactly what the agent is told. You can edit them, restore Studio's version, or turn them off in **Settings → Agent chat**.
- **Suggestions and links back into Studio.** An empty chat suggests a few things to ask, based on what's open. When the agent creates a collection or runs one, its card has an **Open in Studio** button.
- **The chat sits beside the page.** It no longer covers part of the window, so buttons like a collection's **Run** stay visible. Drag its left edge to make it wider or narrower.
- **You can see collection runs.** The status bar shows which step a run is on, including runs the agent started. When a run finishes, a notice says whether it passed, or which step failed and why, with a button to open the run's log. If you started the run from the collection's page, Studio opens the log for you.
- **A clearer local mock label.** A running local mock now reads **Local mock · Running**. Hover it to see the address, or click it to copy the address.
- **The Studio docs are open for contributions.** The pages behind docs.spec0.io/docs/studio now live in this repository under `docs/user/`. There's a new, longer guide to the agent chat, and every page has an **Edit on GitHub** link.

## Fixes

- Long lines in the chat, such as a tool card with a file path, pushed every message past the panel's edge. Text now wraps to the panel's width.
- Agents that called `get_operation`, `send_request` or `add_step` with `operationId` or `operation` instead of `operation_id` got an error. Those names now work.
- `search_operations` failed when an agent asked for an API's operations without search text. It now lists them.

## Good to know

- Claude Agent still needs an Anthropic API key, saved in **Settings → Agent chat**.
- If you point the agent at your own folder, Studio doesn't write its instructions file there. It sends the instructions with the first message instead.
- Collections still run only in Studio. A command-line runner is the next thing we're working on.
- The Windows installer is still not code-signed. See the README for what SmartScreen shows and how to check the download.
