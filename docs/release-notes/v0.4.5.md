Spec0 Studio 0.4.5 makes sure you see when an agent is waiting on you, and makes the schema graph easier to read.

## Notifications

- **A bell in the top bar** lists everything that needs you or happened while you were away: agent requests waiting for an answer, requests nobody answered, Studio and API updates, and collection runs that an agent finished.
- **Answer from the bell.** A waiting request has the same buttons as the approval dialog, **Allow once**, **Don't allow** and sometimes **Allow for this session**, so you can answer from either.
- **Missed requests stay in the list.** An approval nobody answers within five minutes is refused, as before. It now shows under **Missed**, with when and why, and a link to the activity log, so the agent's "timed out" message has an explanation.
- **Studio asks for your attention** while an agent is waiting and its window is behind others: the Dock icon bounces on macOS, the taskbar button flashes on Windows, and the window title says how many requests are waiting.

## Schema graph

- **Straight lines with rounded corners** replace the curves that ran over boxes. A line to a box that sits behind the one it starts from goes round the row, over or under it, instead of back across the graph.
- **Drag boxes** to arrange the graph; the lines follow while you drag.
- **Tidy up** in the graph toolbar puts the boxes you moved back and lays the graph out again.

## Fixed

- In the schema panel next to the graph, long field names, the "required" tag and type badges such as `LineItem[]` no longer run into each other. Names wrap between words, and "required" sits under the name.

## Good to know

- Claude Agent still needs an Anthropic API key, saved in **Settings → Agent chat**.
- The Windows installer is still not code-signed. See the [install page](https://studio-docs.spec0.io/install/) for what SmartScreen shows and how to check the download.

If Studio is useful to you, a star on [GitHub](https://github.com/spec-0/studio) helps other developers find it.
