Spec0 Studio 0.4.6 lays the schema graph out properly: every box placed and every line routed, so a big spec stays readable.

## Schema graph

- **The graph lays itself out.** Boxes go in columns, from the schemas that refer to the ones they refer to, and every line is routed around the boxes, never through one.
- **Each line starts at its field.** A line leaves from the row of the field that makes it, such as `customer` on Order, so you can see which field each line belongs to. A field that isn't listed on the box starts its line at the **+N more** row.
- **No more tangles on big specs.** Lines are kept apart instead of running on top of each other, and they cross far less. On a spec with 250 schemas, crossings went from about 200 to 2.
- **The same layout every time.** Opening the same graph gives the same picture.
- **Drag and Tidy up** work as before. A line to a box you've moved runs straight to it until **Tidy up** lays the graph out again.

## Also new

- **Settings → About** shows your version and lists the open-source packages Studio is built with. Open one to read its licence and notice, or filter by name or licence.

## Good to know

- Claude Agent still needs an Anthropic API key, saved in **Settings → Agent chat**.
- The Windows installer is still not code-signed. See the [install page](https://studio-docs.spec0.io/install/) for what SmartScreen shows and how to check the download.
