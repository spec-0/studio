Spec0 Studio 0.4.6 gives the schema graph a real layout and lets you share variables across environments.

The graph now places every box and routes each line around the boxes instead of through them. A line starts at the field that makes the reference, so you can see which field it belongs to, and on big specs the lines no longer pile on top of each other. Drag and **Tidy up** work as before.

Variables under **Shared** in the Environments dialog now apply in every environment, and when no environment is chosen. An environment only needs the values that differ, and its own value wins.

**Settings → About** lists the open-source packages Studio is built with, along with their licences.

The Windows installer still isn't code-signed. The [install page](https://studio-docs.spec0.io/install/) explains what SmartScreen shows and how to check the download.
