Spec0 Studio 0.4.0 lets your coding agent test APIs through Studio, and adds a chat panel for the agent you already use. You stay in control of what it sends.

## What's new

- **Agents can test APIs through Studio.** The local MCP server used to let an agent read your specs. Now it can also send requests, check a running server against its spec, start a local mock, build collections, run them and read their logs. It uses your environments, auth and certificates, but it only ever sees `{{name}}` for a secret, never the value. Tell your agent "test the Orders API on localhost:8080" and you can watch the collection appear and run in Studio.
- **You approve what an agent does.** The first request to each host asks you: don't allow, allow once, or allow for this session. `DELETE`, `PUT` and `PATCH` to a host outside your computer always ask, even when the host is already allowed. Starting a local mock asks first, and saving a collection to a file asks every time and shows the path. An approval nobody answers is refused after five minutes.
- **Limits you set.** The MCP tab has a list of hosts agents may never call, and a cap on requests per minute (60 to start with).
- **See what agents did.** The MCP tab lists the agents that connected, what you allowed this session, and what each agent sent and got back. Runs an agent started say which agent, and so does the console. **Stop agents** refuses anything waiting, cancels the agents' runs, forgets this session's approvals and stops the server.
- **Agent drafts.** A collection an agent creates is a draft until you keep it. Agents can change their own drafts, but once you keep a collection, or it's one you made, they can only read and run it.
- **Agent chat.** Press ⇧⌘J (Ctrl+Shift+J) or **Agent** in the status bar to talk to Claude Agent, Codex or Gemini CLI inside Studio. Studio starts the agent on your computer and gives it Studio's tools. Type `@` to attach the operation you're looking at, a response, a collection step or a run log. The agent's own permission requests show up as buttons in the chat. It's off until you pick an agent in **Settings → Agent chat**.

## Good to know

- What you type and attach in the agent chat goes to that agent and from there to its model provider. Secret values are replaced with `{{name}}` first, and past chats stay on this computer.
- Claude Agent needs an Anthropic API key. Save it in **Settings → Agent chat**; it's kept in your system's credential store and given only to the Claude agent. Studio doesn't use a claude.ai or Claude Code sign-in for it. Codex can use your ChatGPT sign-in (`codex login`), and Gemini CLI signs in the way it does in your terminal.
- Claude Agent and Codex run through adapter packages that need Node.js. If Studio can't find an agent, set its path in Settings.
- A past chat can be read again but not continued. Sending after **End chat** starts a new session, and the agent won't see the earlier messages.
- Collections still run only in Studio; there's no command-line runner yet.
- The Windows installer is still not code-signed. See the README for what SmartScreen shows and how to check the download.

Thanks to everyone who tried 0.3.0. If something an agent does in Studio surprises you, please tell us in Issues or Discussions.
