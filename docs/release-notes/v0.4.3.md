Spec0 Studio 0.4.3 gives every screen a new design: calmer, easier to read, and more consistent from one screen to the next. It also fixes a few things that were wrong, and the user guide has a new [quick start](https://studio-docs.spec0.io/quick-start/).

## A new design

- **The request workspace.** The address bar is one box: the method, where the request goes ("Local mock :4011", "Hosted mock", an environment or a server), and the path. **Send** has a menu with **Copy as cURL** (`⇧⌘C`) and **Add to collection…**. Request tabs sit above the API's bar, like browser tabs.
- **The request editor.** Body, Params, Headers, Auth and Docs are tabs with counts. The body editor has line numbers and highlighting, with **Format** and **Reset to example** above it.
- **The response.** One line has the status, time, size, where the answer came from, and **Matches Order** or the number of differences.
- **The Docs tab shows the whole operation:** its description (or summary), each parameter, the request body and its fields, and each response with its description and schema.
- **Collections.** Steps lead with their name, show the values they take from earlier steps, and end with the last result. A line above the steps says how the last run went. **Add step** adds an empty request. Runs are named for what happened, such as "Passed · 3 of 3" or "Failed at step 3".
- **Environments.** Variables are a table with a Secret switch, and you add one from the row at the bottom.
- **The schema graph.** Each schema shows its first fields and their types. A toolbar switches between schemas alone and schemas with operations, centres the graph on a schema you pick, and can also show simple types such as named strings and enums.
- **Agent chat.** Tool calls are one-line rows you can open, permission requests are a card with the agent's own choices, and the settings show how each agent runs.
- **Everything else:** the library, Mocks, MCP, History, Settings and the dialogs follow the same design. The top bar shows your organisation's initials when you're signed in, and the status bar at the bottom is the same on every screen.

## Fixes

- **History says where a request went.** A request sent to a local mock used to say "Sent to: Real server". It now names the local mock, the hosted mock, the server, the environment, or a typed URL.
- **A parameter's own example is used.** `example: pay_8Hq2` on a path parameter used to be ignored, and the request went out as `/payments/string`.
- **HTML in descriptions is formatted** instead of showing its tags, as in Stripe's spec. Nothing is rendered as HTML, and links open in your browser.
- **Plurals.** "used in 1 operations" now reads "used in 1 operation".

## Also

- The user guide's screenshots show the new design, and there's a new [quick start](https://studio-docs.spec0.io/quick-start/) page to share with someone trying Studio for the first time.

## Good to know

- Claude Agent still needs an Anthropic API key, saved in **Settings → Agent chat**.
- The Windows installer is still not code-signed. See the [install page](https://studio-docs.spec0.io/install/) for what SmartScreen shows and how to check the download.
