Spec0 Studio 0.4.2 is mostly fixes: response checks that respect nullable fields, a sturdier local mock, and clearer messages when working with Spec0. Most of them came from people outside the team, which we're glad about.

## Fixes

- **A `null` the spec allows is no longer reported as drift.** Studio already accepted `null` for a field marked `nullable: true`, but not when the field also had an `enum`, when it was a nullable `$ref` or `allOf` (the usual way to write a nullable object), or when it had no `type`. A `null` the spec doesn't allow is still reported.
- **The local mock answers `HEAD` with the length a `GET` would have.** It used to send `Content-Length: 0`.
- **An invalid status request no longer hides a valid one.** A broken `X-Mock-Status` header used to stop `?__status=` from being used. Now the first valid one wins, in the same order as before.
- **The local mock also listens on `[::1]`.** Tools that resolve `localhost` to IPv6 first used to get "connection refused".
- **Web pages can't probe a local mock with `<script>` or `<img>` tags.** Studio already refused requests from other websites, but these loads carry no `Origin`, so a page could tell which paths a mock served. They're now refused too, unless they come from a page on your computer, and every response says `X-Content-Type-Options: nosniff`. Opening a mock URL in the address bar still works.
- **Each API's schema graph opens on its own schema.** It used to start on the schema you'd last clicked in another API.
- **Library cards keep their shape on hover.** Refresh, Rename and Remove now sit in the card's top corner instead of squeezing the footer, and they also appear when the card has keyboard focus.

## Working with Spec0

- **A mock key Spec0 can't show again.** Keys made before Spec0 stored them in a recoverable way can't be shown again. Studio now says that plainly and offers **Make a new key**, instead of an error code.
- **Clearer plan limits.** When you reach a limit, Studio says how many you've used and on which plan, for example "You've used 3 of 3 mock servers on the Free plan."
- **Your organisation's plan** is shown in **Settings → Account & Spec0**.

## Also

- The user guide has moved to its own site, [studio-docs.spec0.io](https://studio-docs.spec0.io), and is written in this repository, so anyone can suggest a change to it.
- A faint Spec0 mark sits behind the APIs page.
- The agent chat uses version 2 of the Agent Client Protocol library. Nothing changes in how agents connect.
- Dependency updates, including Tauri 2.12.5.

## Good to know

- Claude Agent still needs an Anthropic API key, saved in **Settings → Agent chat**.
- The Windows installer is still not code-signed. See the README for what SmartScreen shows and how to check the download.

Thanks to @jainarpit for six of the fixes above, each with a clear write-up and tests. If you'd like to help too, [CONTRIBUTING.md](https://github.com/spec-0/studio/blob/main/CONTRIBUTING.md) now explains how to send a change.
