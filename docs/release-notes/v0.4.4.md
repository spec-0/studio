Spec0 Studio 0.4.4 makes it easy to try an API you don't have a spec for: send as many requests as you like, keep them in a collection, and turn them into a spec when you're ready. Agents connected to Studio can now add a spec to your library too.

## Scratch requests

- **As many as you need.** **New request** (`⌘N`, `Ctrl+N`) starts a request to any URL, from anywhere in Studio. It's also in the library and on **+** next to the request tabs.
- **Each one has its own tab and its own last response**, like an operation. The scratch screen lists them next to their History, with duplicate and remove.
- **They're kept as you typed them** until you remove them. The single scratch pad from earlier versions becomes your first scratch request.
- **Add to collection** puts a scratch request into a new or existing collection, with its method, URL, headers and body. It runs with the other steps, and later steps can use values from its response.

## Describe as a spec

- **Describe as a spec** writes a draft OpenAPI 3.1 document from the requests you've sent to one host and the responses you got back. It's on the scratch screen, and on a collection that has steps not in any spec.
- Ids in paths become path parameters (`/users/1` becomes `/users/{userId}`), query names become parameters, and the bodies you sent and received become schemas, with examples from the real values.
- Nothing is sent to build it. Tokens, cookies and API keys are left out of the document and its examples; the kind of auth used is described without its value.
- You see the operations and the YAML before saving. The file opens in your library like any other spec, so Studio checks responses against it from then on. Collection steps it came from are linked to the new operations.

## For agents

- **`open_spec`** lets an agent connected to Studio's MCP server add a spec to your library from a file path or a URL. Studio asks you every time and shows the path or URL. A spec that's already in the library isn't added twice.

## Good to know

- Claude Agent still needs an Anthropic API key, saved in **Settings → Agent chat**.
- The Windows installer is still not code-signed. See the [install page](https://studio-docs.spec0.io/install/) for what SmartScreen shows and how to check the download.

If Studio is useful to you, a star on [GitHub](https://github.com/spec-0/studio) helps other developers find it.
