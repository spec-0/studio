Spec0 Studio 0.2.0 is mostly about finding your way around, and about a few things that previously needed another tool.

## What's new

- **Clearer navigation.** The icon toolbar is replaced by text tabs: APIs, History, Mocks and MCP across the top, and Operations, Schemas, Graph and Document for the API you have open. The schema graph, which used to hide behind an icon, is now a tab of its own. The API's name has its own row, so it is no longer cut short.
- **A Settings page** (⌘, or Ctrl+,) for your Spec0 account, network settings, updates, appearance, the MCP server, and data and privacy.
- **Hosted mock servers in one guided dialog.** Choose "Create mock" on any API you opened from a file or a URL. Studio walks you through signing in, choosing a team, publishing the API inside your organisation and creating the mock, and skips any step you have already done. It keeps the mock's address and key, points your requests at it, and can send a first test request for you. Rebuild and Regenerate key are always available once a mock exists.
- **A local MCP server,** so a coding agent on your computer can see the APIs open in Studio: list them, read specs and operations, search, and, when you are signed in, get a mock's address and key. It is off until you start it, listens only on this computer, needs a token, and never shares secret values.
- **Swagger 2.0 specs open.** Studio converts them to OpenAPI 3.0 when you open them, shows the original in the Raw tab, and says where the conversion may be imperfect.
- **"Open in Studio" links.** The button on Spec0's public API pages can now open an API straight in Studio. Studio always asks before downloading anything, shows where it comes from, and only accepts `https` addresses.

## Fixes

- Switching operations clears the response pane, so an old response is never shown next to a different request.
- A request still running when you switch away now goes to History only, instead of appearing next to another request.
- Signing in from Studio no longer signs you out of the spec0 CLI, and pressing Cancel on the sign-in page stops Studio waiting straight away.

## Good to know

- If you are on 0.1.1 or earlier, download this version by hand once. From 0.1.2 onwards, *Check for Updates…* installs it for you.
- Hosted mocks need a Spec0 account. Everything else works without one.
- The Windows installer is still not code-signed. See the README for what SmartScreen shows and how to check the download.

Thanks to everyone who tried 0.1.x and told us what broke. Please keep doing that, in Issues or Discussions.
